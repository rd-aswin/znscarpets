# Project Guidelines & Strict Instructions

## Core Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: JavaScript (`.jsx` / `.js`)
- **Styling**: Tailwind CSS
- **Package Manager**: `npm`
- **Scope**: Strictly Front-End only (No backend, no external paid tools or services)

---

## Strict Operating Rules & Constraints

1. **No Unprompted Creations or Assumptions**:
   - Do **NOT** assume, guess, or create any component, layout, page, style, or asset on your own.
   - Everything must be instructed directly by the user step by step.

2. **Step-by-Step Implementation**:
   - Wait for explicit user instructions before implementing each component and feature.
   - Follow exact user specifications for every UI element.

3. **Icons & Animations**:
   - Implement icons, motion, or animation libraries only when and as explicitly specified by the user.

4. **Front-End Exclusivity**:
   - Zero backend endpoints or server database requirements.
   - Zero paid third-party dependencies or services.

5. **Maintain Context & Documentation**:
   - Always update `PROJECT_LOG.md` whenever changes, additions, or fixes are made to maintain complete chronological memory of the project's evolution.
